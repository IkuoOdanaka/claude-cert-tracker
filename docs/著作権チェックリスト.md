# 著作権チェックリスト

このプロジェクトは、他社（Anthropic）が公開している資格・コース情報を扱う。
**扱い方を誤ると、学習を助けるどころか権利侵害になる。** 判断がぶれないよう、
基準と手順をここに固定する。

法律の専門家による助言ではない。判断に迷うもの、金銭が絡むもの、
権利者から連絡が来た場合は、自己判断で進めず本人に確認する。

## 基準: 事実は載せてよい、表現は載せない

| 載せてよい（事実） | 載せない（他社の表現） |
| --- | --- |
| 資格名・コース名・レベル | 公式サイトの説明文 |
| 価格・所要時間 | その**翻訳**（翻訳は二次的著作物） |
| どの資格にどのコースが含まれるか、その順序 | 教材・スライド・動画の中身 |
| 公式ページの URL | 試験問題（原文・翻訳・言い換えのいずれも） |
| 自分で書いた注記・分類・タグ | 公式のロゴ・画像 |

### 特に間違えやすい点

- **「自分の言葉で要約した」は安全とは限らない。** 元の文を1対1でなぞった要約や翻訳は、
  表現を借りている。実際にこのプロジェクトでは、公式の説明文をほぼ直訳した `summary` を
  25 コース分持っていて、あとから全削除した。
- **短い文なら大丈夫、とも限らない。** 1文が短くても、25件まとめて訳せば
  「説明文の集合を再現したもの」になる。
- **説明が必要なら、公式ページへのリンクで済ませる。** 内容の説明はリンク先の仕事。
  自分で書き起こす必要はない。

## 商標

「Claude」「Anthropic」は Anthropic PBC の商標。**どの製品・どの資格の話をしているかを
示すため**の言及は通常問題にならないが、次を守る。

- 提携・後援・公式であるかのような表示をしない
- ロゴや公式のビジュアルを使わない
- 「非公式である」ことを、探さなくても目に入る場所に常に出す
  （このサイトではヘッダーのバッジとフッター）

## PR を出す前のチェック

データや文章を足したときは、次を確認する。

- [ ] 追加したテキストは、公式サイトの文を**訳した／なぞった**ものではないか
- [ ] `data/*.json` に自由記述の長文フィールドを増やしていないか
      （`npm test` の「掲載範囲(事実情報のみ)」が検出する）
- [ ] 模擬試験の問題は自作か。`sourceRefs` に根拠の URL があるか
- [ ] 公式のロゴ・画像・スクリーンショットを含めていないか
- [ ] 非公式である旨の表示を壊していないか

## 自動で守っている部分

`tests/data-integrity.test.ts` の「掲載範囲(事実情報のみ)」が、CI で次を落とす。

- `data/courses.json` に許可した以外のフィールドが増えた場合
- `certifications.json` に `summary` / `description` が復活した場合
- `targetAudience` が長文になった場合（職種ラベル以外が入った合図）

自動チェックは「増えていないこと」しか見られない。
**訳文かどうかは人が見るしかない**ので、上のチェックリストは省略しない。

## 権利者から連絡が来たら

- 自己判断で反論しない。まず本人（リポジトリ所有者）に共有する
- 指摘された箇所は、確認が済むまで公開を止めるか、該当部分を外す
- 連絡窓口はリポジトリの Issue。README と「このサイトについて」に明記している
